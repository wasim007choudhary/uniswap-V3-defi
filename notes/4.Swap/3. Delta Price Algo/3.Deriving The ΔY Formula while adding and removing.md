

# Part 3 — Deriving The ΔY Formula

Now let's answer the second half of the lesson.

Instead of swapping **X**,

suppose the trader swaps

```text
ΔY
```

Again,

forget the mathematics for a moment.

Think exactly like the pool.

---

# Imagine This

There is still only one LP.

```text
Price Range

$4 ----------------------------- $8

Liquidity = L
```

For the purpose of this derivation,

assume the current price starts at

```text
Plower
```

Graphically

```text
Plower ----------------------------- Pupper
▲
Current Price
```

Again,

this is ONLY for the derivation.

Normally,

the current price can be anywhere inside the range.

---

# The Trader Arrives

The trader says

```text
I want to swap

ΔY
```

Immediately,

we already know what happens.

```text
More Y enters

↓

Y becomes less scarce

↓

Price increases

↓

Price moves RIGHT
```

Graphically

```text
Plower ----------------------------- Pupper
▲
Current Price

Trader adds ΔY

↓

Price moves RIGHT

↓

Somewhere toward Pupper
```

Again,

the trader never tells the pool

```text

```

The trader only provides

```text
ΔY
```

The pool must calculate

> Exactly where should the new price stop?

# 👶 Child Analogy — Climbing Stairs

Imagine you're standing at the bottom of a staircase.

```text
Top Floor

│

│

│

Bottom Floor
```

Adding X pushed us DOWN the stairs.

Adding Y pushes us UP the stairs.

> Where are you now?

# Which Equation Do We Already Know?

Earlier,

we derived

```text
y = L√Pupper − L√Plower
```

Originally,

this equation answered

> How much token Y exists inside this liquidity position?

Now,

during the swap,

the trader tells us exactly how much Y enters.

Therefore,

replace

```text
y

↓

ΔY
```

Result

```text
ΔY = L√Pupper − L√Plower
```

Exactly the same idea as ΔX.

Nothing magical changed.

---

# What Is Unknown?

The pool already knows

```text
ΔY
```

It already knows

```text
Liquidity
```

It already knows

```text
√Plower
```

The only thing it does NOT know is

```text
√Pupper
```

which represents

the new price after the swap.

---

# Step 1

Move

```text
L√Plower
```

to the left.

Result

```text
ΔY + L√Plower

=

L√Pupper
```

Why?

Exactly the same reason as before.

We are slowly exposing

```text
√Pupper
```

---

# Step 2

Divide everything by

```text
L
```

Result

```text
ΔY/L

+

√Plower

=

√Pupper
```

Rearrange

```text
√Pupper

=

√Plower

+

ΔY/L
```

Done.

That's it.

---

# Wait...

Why was this derivation so much easier?

Notice something.

For ΔX,

we had

```text
1 / √Price
```

Because the unknown was inside a denominator,

we had to

- make common denominators,
- combine fractions,
- multiply,
- divide,
- rearrange much more carefully.

For ΔY,

the unknown wasn't inside a denominator.

It was already on top.

So we only needed

- move one term,
- divide by L.

Finished.

---

# Final Formula — Adding ΔY

```text
√Pafter

=

√Pbefore

+

ΔY/L
```

For THIS derivation

```text
Pbefore = Plower

Pafter = Pupper
```

Again,

these names are only being used because of how we started the derivation.

Later,

everything becomes

```text
Pbefore

↓

Pafter
```

---

# Removing ΔY

Now imagine the opposite.

Instead of adding Y,

the trader removes Y.

Everything stays exactly the same.

Only

```text
+ΔY
```

changes into

```text
-ΔY
```

Result

```text
√Pafter

=

√Pbefore

-

ΔY/L
```

---

# General Formula

Combine both cases.

```text
√Pafter

=

√Pbefore

±

ΔY/L
```

Use

```text
+
```

when adding ΔY.

Use

```text
-
```

when removing ΔY.

---

# Compare The Two Formulas

Now put them side by side.

## ΔX

```text
√Pafter

=

L√Pbefore

/

(L ± ΔX√Pbefore)
```

Notice

Huge fraction.

Lots of terms.

---

## ΔY

```text
√Pafter

=

√Pbefore

±

ΔY/L
```

Notice

Just

```text
Current √Price

+

or

-

ΔY/L
```

Much simpler.

---

# Why Are They Different?

This is actually one of the most beautiful parts of Uniswap V3.

Token X changes price

through

```text
1 / √Price
```

Token Y changes price

through

```text
√Price
```

Mathematically,

that makes the ΔX equation much more complicated.

The ΔY equation stays linear.

That is why,

inside

```text
SqrtPriceMath.sol
```

there are different implementations for

- token0 (X)
- token1 (Y)

The protocol isn't making life difficult.

The mathematics itself is different.

# 📝 Key Takeaways

- The original `x` and `y` equations calculate **token amounts**, not Active Liquidity.
- This lesson reuses those equations to answer a different question:
  - **Given a swap amount, where does the price move?**
- During the derivations, `Plower` and `Pupper` are temporarily used as the starting price only to simplify the algebra.
- In real swaps, the current price is usually somewhere inside the active range.
- Adding **ΔX** moves the price LEFT.
- Removing **ΔX** moves the price RIGHT.
- Adding **ΔY** moves the price RIGHT.
- Removing **ΔY** moves the price LEFT.
- The ΔX derivation is more complex because the unknown appears inside a denominator.
- The ΔY derivation is much simpler because the unknown is already on top.
- The generalized formulas are:

```text
ΔX

√Pafter

=

L√Pbefore

/

(L ± ΔX√Pbefore)
```

```text
ΔY

√Pafter

=

√Pbefore

±

ΔY/L
```

- These equations form the mathematical foundation for `SqrtPriceMath.sol`.
- `SqrtPriceMath.sol` is simply an optimized Solidity implementation of the mathematics derived in this lesson.
